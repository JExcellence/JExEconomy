# Contributing

Bug reports and ideas are welcome as issues. Please include the JExEconomy version, the server software and version, the database and the relevant log lines.

This repository cannot be built on its own, see the README. Pull requests can be reviewed, but changes are built and tested in the private repository before they are released, so a small, focused change or a clear description of the problem works best.

By contributing you agree that your contribution is licensed under the terms in [LICENSE](LICENSE).

The code follows these rules: at most 15 cognitive complexity per method and 7 parameters, no inline comments, all player text in the translation files in English and German, and no blocking database work on a server thread.
